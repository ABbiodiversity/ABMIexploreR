# Coefficient extraction

This function extracts the stored coefficients and provides a table or
summary figure.

## Usage

``` r
coefficient_extraction(species, model = NULL)
```

## Arguments

- species:

  Unique Species ID. If defined as "All", the complete coefficient table
  will be provided to the user.

- model:

  Vector defined as "Vegetation" or "Soil" that provides the relevant
  coefficients.
